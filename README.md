# Governable Spaces — MCP Server

> **Status: in development.** This MCP is a planned port of Nathan Schneider's *Governable Spaces: Democratic Design for Online Life* (UC Press / Luminos, 2024) into an MCP server for AI assistants. The repo exists and the build is queued; there's no live deploy yet.

When complete, it will give AI assistants like Claude tools for applying Schneider's framing to real situations — diagnose implicit feudalism in an online community, surface democratic-mediation precedents, propose governance forms (sortition / federated / plural-voting / etc.) for a new community, find grounded quotes for writeups.

## Source

Nathan Schneider, *Governable Spaces: Democratic Design for Online Life* (University of California Press / Luminos, 2024). Free to read and download (PDF / EPUB / MOBI):

> https://luminosoa.org/books/m/10.1525/luminos.181
